# Media folder

Drop movies you own or are licensed to screen here (`.mp4`, `.webm`, `.m4v`).
They are served by the theater server at `/media/<filename>` and can be
queued for synchronized playback by the theater host.

Never add content you do not have the rights to stream. Licensed streaming
services (Peacock, Netflix, Disney+…) do not authorize embedding inside
third-party games; those are offered as external links instead.
